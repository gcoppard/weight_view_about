# Support & Help

Thank you for using WeightView! This page will help you report issues, request features, and get answers to common questions.

---

## 📬 How to Get Support
If you encounter a bug, have a question, or want to suggest a new feature, please open an issue:

👉 **[Open an Issue](https://github.com/YourUsername/YourApp/issues)**

When submitting an issue, please include:
- A clear description of the problem
- Steps to reproduce it
- Expected vs. actual behavior
- Device model (e.g., iPhone 12)
- iOS version
- App version
- Screenshots (if applicable)

---

## 📝 Feature Requests
We welcome suggestions!

If you have ideas that could make the app better, open a **Feature Request** issue and include:
- What you’d like to see
- Why it’s helpful
- Any relevant examples or mockups

---

## ❓ Frequently Asked Questions

**Q: My weight entries aren’t saving. What should I do?**  
A: Make sure you’re on the latest version of the app. If the issue continues, open a bug report.

**Q: Can I export my data?**  
A: Exporting features may be added soon. Check open or upcoming feature tickets.

**Q: Does the app sync across devices?**  
A: Sync is not yet available, but it’s on our roadmap.
